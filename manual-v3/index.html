도면에서 결과 확인까지

작업 순서대로 읽고, 필요한 설명으로 바로 이동하세요.

페이지 구조를 검토하는 시안입니다. 아래 관저고 예제는 설명용 도식이며 실제 CAD 실행 화면이 아닙니다. 기능별 실촬영 자료는 다음 제작 단계에서 채웁니다.

01

작업 준비

먼저 대상 도면과 설정을 확인합니다

작업할 DWG에서 FlowWork를 열고, 관로선과 표고 문자의 레이어가 수집 설정과 일치하는지 확인합니다.

설정 설명은 어디까지 제공하나요?

이 위치에 설정 화면의 해당 항목을 확대한 캡처와 설정값 확인 절차를 배치합니다. 본문 흐름을 유지하면서 상세 기준을 펼쳐 읽는 구성입니다.

02

대표 사례 · 관저고

관로 양 끝의 문자를 읽습니다

START 쪽 관저고는 상류 필드, END 쪽 관저고는 하류 필드에 연결됩니다. 아래에서 한쪽 끝을 선택해 원본 표기와 대응하는 값을 확인하세요.

START와 END는 높이가 결정하나요?

현재 구현은 CAD 관로선의 시작점과 끝점을 기준으로 합니다. 관저고가 높다는 이유만으로 자동으로 START가 되는 것은 아닙니다.

03

수집 결과 검토

값과 진단을 함께 확인합니다

원본 문자를 찾지 못한 상태와 직접 지정한 이후의 차이를 비교해 보세요.

상류 관저고0.00 m

관저고 누락 경고. 0.00을 원본에서 읽은 정상값으로 판단하지 않습니다.

상태 비교는 설명 예제입니다. 실제 결과 화면은 동일 관로의 수정 전후 캡처로 제작합니다.

04

수동 매핑

누락된 끝점에 올바른 문자를 지정합니다

  1. 관로와 끝점 확인

    목록에서 관로를 선택하고 START와 END를 확인합니다. 상류 관저고가 누락됐다면 START 쪽 원본 문자를 찾습니다.

  2. 상류 관저고 직접 지정

    해당 필드의 직접 지정 기능을 선택한 뒤 CAD의 문자 선택 안내를 확인합니다.

  3. 원본 문자 선택

    상류 관저고 텍스트를 선택합니다. 선택을 취소하려면 Esc를 누릅니다.

  4. 자동 재수집 결과 비교

    표시된 값이 선택한 원문과 같은지, 누락 진단이 해소됐는지 확인합니다.

숫자를 직접 입력하는 기능인가요?

수동 매핑은 CAD 원본 문자 객체를 연결하는 기능입니다. 잘못 연결했다면 같은 필드에서 올바른 문자를 다시 지정합니다.
